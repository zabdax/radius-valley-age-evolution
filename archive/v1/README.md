# Archived v1 material (historical, superseded)

This directory preserves the earlier version of the analysis for provenance and
auditability. **None of these files describe the current v2 results.**

For the manuscript-grade results, use [`repro/v2/`](../../repro/v2/) and read
[`REPO_STATUS.md`](../../REPO_STATUS.md), which lists the superseded values.

## What is here

| Path | What it is |
|---|---|
| `notes/` | Early analysis notes (ROADMAP, REPORT, INVENTORY_AND_ABSTRACT). Contain the original 120-replicate FPR/coverage values. |
| `legacy_draft/` | The earlier paper draft and its compiled PDF. Uses the pre-audit headline numbers. |
| `manuscript/` | Earlier manuscript revision records and local build files (AASTeX styles, figure copies). No current source is here. |

## Why keep it

The v1 files document how the analysis evolved: the audit that moved the 8x
detection estimate from 18.7% to 23.2%, the identification of the null FPR
inflation, and the period-mixing diagnosis. Deleting them would remove the
decision trail behind the current methodology.

They are kept out of the active tree so that a newcomer browsing the repository
does not mistake historical values for current ones. If you need the v1 state
exactly as archived, use the immutable Zenodo v2.0.1 record
(doi:10.5281/zenodo.23007310).
